# Number Guessing Game

===Description===
This is a simple Python number guessing game created as part of the T4G Cohort 5 assignment.

The program generates a random number between 1 and 100, and the player tries to guess it. After each guess, the program gives feedback on whether the guess is too high or too low until the correct number is guessed. At the end of each game, the player can choose to play again or exit.

===Features===
- Generates a random number between 1 and 100
- Validates user input
- Tells the player if the guess is too high or too low
- Counts the number of attempts
- Replay option after each game

===Requirements===
- Python 3.x

===How to Run===
1. Clone this repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project folder:
   ```bash
   cd t4g-cohort5-guessing-game
   ```

3. Run the game:
   ```bash
   python3 number_game.py
   ```
